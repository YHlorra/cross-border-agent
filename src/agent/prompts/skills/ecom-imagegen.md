# 电商生图 SOP（六要素框架）

## 工作流（6 步）

① 定用途与画幅 → ② 备素材与红线 → ③ 六要素拆提示词 → ④ 多方案生成择优 → ⑤ 合规检查 → ⑥ 多尺寸导出

- 画幅对照：主图 1:1、场景图 4:3/3:2、社媒竖图 3:4/9:16、详情长图 1:2~1:3、Banner 3:1~4:1
- 多方案：每版出 2-3 张候选，按「卖点清晰度 / 质感真实度 / 一致性」择优

## 六要素提示词（组装顺序固定，缺一不可）

| # | 要素 | 覆盖内容 | 反例（不可用） |
|---|------|----------|----------------|
| 1 | 主体 | 品类、材质、颜色、形态、核心卖点细节 | "一个杯子"（太泛） |
| 2 | 场景 | 环境、道具、氛围、季节/时点 | "好看的背景"（不可执行） |
| 3 | 光影角度 | 光源方向与软硬、拍摄角度、景深 | "拍得高级"（不可执行） |
| 4 | 构图画幅 | 主体占比、位置、留白、**画幅比例显式写出** | 缺比例参数（无法落版） |
| 5 | 质感风格 | 写实/极简/高级感（风格词不得与品类冲突） | — |
| 6 | 文字与合规 | 无文字 / 或引号标出准确文案；禁水印 | 画面文字与文案不一致 |

**空模板**（字段可直接填充）：

```
[主体] {品类}，{材质}，{主色}，{形态/结构}，{核心卖点细节}；
[场景] {环境}，{道具}，{氛围}，{季节/时点}；
[光影] {光源方向}，{软硬}，{拍摄角度}，{景深}；
[构图] 主体占比{百分比}，{位置}，{留白}，画幅 {比例}；
[风格] {写实/极简/…}，{风格关键词}；
[文字] {无文字 / 或画面仅保留"{文案}"}，禁止出现水印与多余标识。
```

**图生图**（基于原图）：保持原商品的颜色/材质/造型与细节不变，仅替换背景/光源/风格；不改变商品外观特征。

## 平台渠道差异速查

| 渠道 | 比例 | 侧重点 | 注意 |
|------|------|--------|------|
| Amazon | 主图 1:1 白底、主体 ≥85% | 信息明确、白底合规 | 主图禁文字/水印/促销条 |
| TEMU | 1:1 商品卡 | 性价比直给 | 标签清晰；防过度修图失真 |
| TikTok Shop/社媒 | 3:4 / 9:16 竖图 | 原生感、使用场景 | 字幕文案留安全区 |
| 独立站 | 3:2 / 4:3 + 长图 1:2~1:3 | 品牌感、生活方式 | 每屏一个卖点 |

## 合规检查清单（生成后必过，任何一条不满足即返工）

- [ ] 无第三方 logo、卡通形象、专利外观（易侵权）
- [ ] 无夸大/绝对化宣称（"100%""最便宜""最佳"等平台禁词）
- [ ] 无医疗、功效、虚假参数类表述
- [ ] 无水印、二维码、联系方式等干扰元素
- [ ] 画面文字与填写文案完全一致（若出字）
- [ ] 尺寸/比例与投放渠道要求一致，主体未被裁切
- [ ] 模特出镜服饰与卖点一致，无违规暴露

## 一致性与红线

- 单商品多图：**主体、风格两要素保持不变**，保证整套视觉统一。
- 红线：生图不用于制造虚假对比、伪造认证标识或侵权素材；失败/比例非法/合规命中如实报错，不伪造 URL。
