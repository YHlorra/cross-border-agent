# Listing 文案方法论（关键词布局 SOP）

## Listing CLI 调度（工具分工）

| 命令 | 什么时候用 |
|------|------------|
| `run_listing(candidate_json)` | 有明确候选商品（选品报告卡里的候选）且要**流水线重生成**草稿时——内部走 LLM 起草+合规校验+自动修复闭环，产出草稿卡并落库。candidate_json 原样引用选品结果里的候选对象，不要编造字段。 |
| `save_listing(listing_json, candidate_json?)` | 你**按本方法论自由起草**了 Listing（例如用户给了明确卖点/素材、或要按三风格变体出定制版）后，把它存入 Listing 列表——程序化校验（字符数/禁令/字节预算）→ 落库 → 草稿卡。校验返回 hard_failed 时按 issues 修正后重新保存。 |
| 探测层（search_amazon 等） | 起草前查竞品标题/价格/评分做对标；关键词来源见四级分配。 |

判断标准：素材齐、要标准草稿 → run_listing；要按用户特定意图定制 → 你起草 + save_listing。**不要把未起草的空想 JSON 塞给 save_listing**——先按下面各节把文案写扎实。

## 标题公式

`品牌 + 主关键词（前 50 字符内）+ 核心属性 + 次要关键词 + 差异化卖点`；相关时含尺寸/颜色/数量。

- 主关键词必须落在前 50 字符（A9 权重最高区）。
- 硬约束（字符数、禁用字符、禁促销语/主观断言）由校验层程序化强制，见 draft 提示词与 validators；写作时直接遵守。

## 五点分工模板（每条一个职责）

1. 核心功能 + 主关键词
2. 使用场景
3. 材质品质 + 信任信号
4. 包装内容 / 兼容性
5. 差异化保障

- 句式为句子片段、结尾不加标点、首字母大写；讲好处，不做参数堆砌。

## 关键词四级分配（生成后必做覆盖率自检）

| 级别 | 去向 |
|------|------|
| 主要关键词 | 标题 |
| 次要关键词 | 五点描述 |
| 三级关键词 | 产品描述 |
| 长尾关键词 | 后台搜索词（≤250 字节，超限整个字段被忽略；不得与标题/五点重复，禁竞品品牌词/ASIN/主观评价词） |

**覆盖率自检 ≥90%**：目标关键词未覆盖的，回流到后台搜索词补齐。

## 内容写法通则

- **具体数字声明优于空泛形容词**："1.2mm 厚不锈钢" 优于 "premium quality"；不承诺产品做不到的事。
- 禁用内容：促销语（free shipping / best seller）、主观断言（#1 / top rated / amazing）、退款保证类措辞（money-back guarantee）、emoji 与特殊符号、描述中 HTML/链接/联系方式。
- 侵权红线：标题/五点/搜索词不得出现他人商标与竞品品牌词（可致 ASIN 抑制）。

## 站点语言匹配（强制）

输出语言必须匹配市场站点：US→英文、DE→德文、JP→日文……即使卖家沟通语言是中文，Listing 产出一律用站点语言。

## 事实锁定纪律（防幻觉，先于一切文风）

Listing 里编造一个不存在的认证、参数或功效，代价是绩效、差评甚至下架——
比文案平庸严重得多：

- **只写输入事实里真实存在的特性**。卖家没给的参数、认证、承诺，宁可
  留空也不编造；"If unsure, leave it out"。
- 数字与规格必须能回溯到输入（选品候选数据 / 卖家笔记 / 语料库商品字段）。
- claim 类禁令（价格/物流/库存/认证）由平台规则 skill 与校验层强制，
  文案层的第一道防线就是不引入这些主题。

## 三风格变体（同一产品生成多版时用）

温度扰动只会产生同义改写；真正"不一样"的三个版本来自三种**视角**：

| 风格 | 目标买家 | 写法 |
|------|----------|------|
| 保守规格型 | 比价模式，同时开着 5 个同类 Listing | 标题关键词密集、硬规格前置；五点只讲可测量事实（尺寸/材质/认证/兼容性），数字胜过形容词 |
| 均衡主流型 | 快速浏览的大多数 | 标题=主关键词+1 个情绪钩子+2 个硬规格；五点好处型与特性型各半配对 |
| 创意情绪型 | 移动端快速滑动、冲动购物 | 标题用痛点/情绪钩子开头——**亚马逊例外**：标题仍守关键词规则，情绪钩子挪到五点第 1 条；描述用一句场景化开场 |

## 本地化 ≠ 翻译

站点语言匹配解决"用什么语言"；本节解决"用什么思维方式写"。机翻腔
在德日站点直接折损信任：

| 站点 | 思维要点 |
|------|----------|
| 英国 | 英式拼写与词汇（colour / organise / favourite），避开美式文化梗，货币参照 GBP |
| 澳新 | 英式拼写，语气比英美更随和友好 |
| 加拿大 | 英式拼写+美式词汇混用（colour 但 truck / elevator） |
| 德国 | 全文德语，行动号召用敬称 Sie；参数要显式（材质/尺寸/能效/质保）；**忌营销空话——德语语境里空话=不可信** |
| 法国 | 全文法语，vouvoiement 尊称；可侧重优雅与工艺叙事 |
| 日本 | 全文日语，重安心・信頼・丁寧；详细规格与售后语言是信任来源 |

完整格式规范（含官方来源与时效标注）见 docs/11-listing-format-compliance-research.md；平台级数字规则与 claim 禁令见 ecom-listing-platform-rules。
